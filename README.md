# 食几何时(Hunger Or harvest)

## 项目简介
食几何时（Hunger Or Harvest）是一款聚焦于农业生产的模拟经营类游戏，玩家将面对一片因为饥荒而废弃的村落，通过调度村民、积累资源，不断研发古代农业科技、修建建筑、开拓土地，以此吸引更多的村民，从而复兴、壮大村落。在建设村落中，你会遇到天灾人祸等挫折阻碍，身为管理者的你能否从古代中华农耕文化中汲取知识与力量对抗饥荒，复兴村落呢？
